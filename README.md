One sentence, 146 characters — the modern internet explained to a traveler from 1800, in words they could already know:

> It is a library where every book answers back when you ask it a question, and any man may speak with a stranger across the sea from his own chair.

`main.py` keeps the sentence as data and writes it to `/output/entry.txt` only after the 1–200 character, single-sentence gate checks out at run time, including a check that no word in it was coined after 1800.

## Run it

```sh
python3 main.py
```
